The FE code: structure and design choices

How fem/ solves quasi-static, finite-strain mechanics with growth & remodeling (G&R) materials, and why it is built this way. Each section gives the formula, where it is in the code, and the reason for the choice. Where a choice was settled by a test, the numbers are included.

Units: mm, MPa, days. Files: fem/core.py (System, solvers), fem/elements.py, fem/mesh.py, fem/tensor3.py, fem/pytree.py. Verification in verification/.

1. Overview

The FE code knows nothing about growth and remodeling. It needs only one thing from each integration point: the Cauchy stress for a given deformation gradient. The G&R model (hcmm, hcmm.core_implicit, fcmm) is plugged in as a module with three functions:

sigma, aux = model.sigma_solver(state, F)   # pure: stress at a trial F, state not changed
state      = model.commit(state, F, aux)    # once per step, on the converged F
J_target(state)                             # optional, hybrid element (default 1)

Without a model, System(mesh) uses Elastic: the state at a Gauss point is a material, and \(\sigma = \texttt{material.sigma}(F)/J\).

Why this split

The split mirrors an Abaqus UMAT: the stress goes into equilibrium, and the state variables (STATEV) are written once the increment has converged. Newton evaluates the stress at many trial \(F\), so sigma_solver must not change the state. Otherwise a rejected iterate would leave growth behind. Keeping the FE side independent of G&R means:

  • the same FE code runs HCMM, FCMM, the implicit HCMM and plain materials;
  • the FE code is verified against closed-form mechanics alone (section 16), before G&R is added;
  • the single-point driver verification/material_point.py uses the exact same interface. This allows the FE result on one element to be checked against the material point (agreement \(\le 4\times10^{-11}\)).

2. Why JAX

Exact tangents for free

The consistent tangent of a G&R material is long and error-prone to derive by hand. This is especially true for the implicit HCMM, where the stress depends on \(F\) through an inner Newton solve. Forward AD gives it exactly, so the outer Newton converges quadratically.

Gradients through the whole simulation

The project's goal is to identify parameters from patient data. Reverse-mode AD plus a custom adjoint at each equilibrium (section 14) gives \(\mathrm{d}(\text{result})/\mathrm{d}(\text{all parameters})\) through prestress and hundreds of G&R steps.

Vectorized Gauss points

vmap over Gauss points and lax.map over element batches turn per-point model code into vectorized kernels. The model is written for one point only.

State as pytrees

The mixture state per Gauss point is a registered pytree (fem/pytree.py). Its leaves get the leading axes (n_el, n_gp) (broadcast_state), so jit, vmap and grad all work on it directly.

float64 is required

fem/__init__.py enables jax_enable_x64. In float32 the residual chatters at about \(\pm4\times10^{-7}\), so tolerances of \(10^{-10}\) can never be met, and the adjoint loses its digits.

The split between JAX and NumPy/SciPy is deliberate. Everything per element or per Gauss point (stresses, tangents, residuals) is JAX. Sparse assembly, the linear solver and the Newton control logic are NumPy/SciPy, because sparse direct solvers do not exist in JAX and the control logic has data-dependent branches.

3. Formulation: total Lagrangian

Everything is integrated over the reference configuration. With the shape-function gradients computed once for the reference mesh:

$$F = I + \sum_a u_a \otimes \frac{\partial N_a}{\partial X},\qquad P = J\,\big(\sigma(\hat F) - q\,I\big)\,F^{-T},\qquad f^{\text{int}}_{ai} = \sum_g w_g\, P_{iJ}\,\frac{\partial N_a}{\partial X_J}$$

Here \(w_g = w_g^{\text{ref}}\det(\partial X/\partial \xi)\) (geometry). \(\hat F\) is the deformation gradient the material sees (\(=F\) except with F-bar), and \(q\) is the element pressure of the hybrid element (otherwise 0). The residual is \(r = f^{\text{int}} - f^{\text{pressure}}(u) - f^{\text{dead}}\) (_residual).

Why total Lagrangian
  • G&R state lives on material points. \(\rho\), \(F_r\) and \(F_g\) belong to a piece of tissue, not to a point in space. In a total Lagrangian code, Gauss point \(g\) of element \(e\) is always the same tissue.
  • Precompute once. \(\partial N/\partial X\) and \(w_g\) are computed once in System.__init__, and a negative \(\det(\partial X/\partial\xi)\) is rejected there. No geometry is recomputed per iteration.
  • Prestress fits naturally. The imaged geometry is the loaded in-vivo state. It becomes the reference configuration, and a deposition stretch \(G\) inside the material makes it an equilibrium at \(u=0\) (section 15).
Why the model returns Cauchy stress

The constrained mixture rule is written in Cauchy stress, \(\sigma = \sum_j (\rho^j/J)\,\sigma^j(F_e^j)\), and the UMATs also return Cauchy stress. The FE code does the pull-back \(P = J\sigma F^{-T}\) itself, so models never deal with first Piola stresses.

Apart from picking the face type, fem/core.py does not branch on the element type: it uses only element_for(n_nodes) and the arrays that returns.

Why these two
  • hex8 is the most efficient element on structured tube meshes: few nodes, and a clean mesh through the wall thickness. Full 2×2×2 integration avoids hourglass modes. Volumetric locking is handled by the element formulation instead (sections 5–6), not by reduced integration, which would need hourglass control.
  • tet10, not tet4. Real carotid geometries come from image segmentation and are meshed with tetrahedra. tet4 has constant strain, is far too stiff in bending and locks badly when nearly incompressible. tet10 is quadratic and converges faster than hex8 on the tube (error ratio about 7 per refinement vs about 4, section 16). It also pairs with a constant pressure into a stable P2/P0 hybrid element.
  • Curved edges. In the structured generator the tet10 midside nodes are mapped from index space, so element edges follow the curved wall.

5. Volumetric locking and the three formulations

Arterial tissue is nearly incompressible, with bulk modulus \(K \gg \mu\). With low-order elements, the displacement field cannot deform at constant volume at every Gauss point. The element becomes far too stiff: it locks. System(..., element=...) offers three formulations:

"standard"

\(\hat F = F\). Correct for compressible materials and the reference for patch tests. Locks as \(K/\mu\) grows.

"fbar" (de Souza Neto et al. 1996)

$$\hat F = \Big(\frac{J_0}{J}\Big)^{1/3} F,\quad J_0 = \det F(\text{centroid})$$

The volume change is taken at the element centre, so each element has one volumetric constraint instead of eight. Displacement-only, and works with any compressible material.

"hybrid" (Q1/P0, P2/P0)

$$\sigma_{\text{tot}} = \sigma(F) - q\,I,\quad \int_{\Omega_e}(J - J_{\text{target}})\,\mathrm{d}V = 0$$

One extra pressure unknown \(q\) per element enforces the volume exactly in the element average. The material returns only the deviatoric part.

Why F-bar is not the default

In a single load step F-bar is as accurate as hybrid. In long G&R runs with \(K/\mu \gtrsim 10^3\), however, it develops hourglass-type modes and Newton eventually fails. The cause is that the volumetric part of the stress is controlled only by the centroid \(J_0\), and there is no hourglass stabilization. F-bar also still needs a finite \(K\): large \(K\) makes the system ill-conditioned and \(K\) is a fake parameter. Hybrid removes \(K\) altogether.

Decision

Use hybrid with NeoHookeanInc elastin for arterial G&R. Use standard only for compressible tests, and fbar only for moderately compressible materials in short runs.

6. The hybrid element in detail

Unknowns and equations

The unknown vector is \(x = (u, q)\), with one \(q_e\) per element appended after the displacement dofs (n_x = n_dof + n_elem, _split). Per element:

$$r_u = \sum_g w_g\, J\,(\sigma - q I)\,F^{-T} : \nabla_X N,\qquad r_q = -\sum_g w_g\,\big(J - J_{\text{target}}(\text{state})\big)$$ $$K_e = \begin{pmatrix} K_{uu} & K_{uq}\\ K_{uq}^T & 0\end{pmatrix},\qquad K_{uq} = -\sum_g w_g\, J F^{-T} : \nabla_X N$$

Why \(J_{\text{target}}\) and not \(J = 1\)

This is the central point of combining the hybrid element with G&R. Growth adds or removes mass, so the tissue volume changes with \(F_g\). Remodeling (\(\det F_r = 1\)) and the incompressible elastic response (\(\det F_e = 1\)) do not change the volume, so

$$J = \det F_e\,\det F_r\,\det F_g = \det F_g \quad\Rightarrow\quad J_{\text{target}} = \det F_g = \frac{\rho_{\text{tot}}}{\rho_{\text{tot}}(0)}\ \ (\text{Eq. 6/7})$$

The model provides it (hcmm.J_target(mixt) = det3(mixt.F_g)), and the FE code calls it per Gauss point (jax.vmap(self.J_target)). Without a model, it defaults to 1. With \(J=1\), a growing incompressible wall could not thicken, and the pressure \(q\) would absorb the growth as a spurious hydrostatic stress.

Design choices

  • Constant pressure per element (P0). This is the simplest pressure space. For tet10 (P2/P0) it is inf-sup stable. For hex8 (Q1/P0) it is the classic mean-dilatation element (Abaqus C3D8H). It is not strictly LBB-stable, but in practice it converges at the same rate as F-bar (table above) and shows no pressure checkerboarding on the tube meshes.
  • Pressure kept as a global unknown, not condensed. With an incompressible material, \(K_{qq} = 0\) (there is no volumetric energy). Static condensation needs \(K_{qq}^{-1}\), so \(q\) stays a Lagrange multiplier. The price is a saddle-point system with a zero diagonal block. That decides the linear solver (section 10).
  • The material returns only the deviatoric stress. NeoHookeanInc.sigma is \(2C_{10}(B - \tfrac{I_1}{3}I)\), and the pressure is "added by the solver". Exported total stresses (fields) subtract \(q_e I\) again, using last_p.
  • Scaled pressure residual. \(r_q\) has units of volume. Newton checks \(|r_q| < \text{tol}\cdot V_e\) (_p_scale = element volume) instead of mixing it with forces.
  • Warm start. The converged pressures are stored in last_p and used as the initial guess for the next solve. In a G&R step the pressure field changes little, so Newton starts close to the solution.
  • Generality. The same code builds Q1/P0 and P2/P0, because q enters only through \(J\) and \(F^{-T}\) at the Gauss points.

7. Element tangent by automatic differentiation

The tangent is consistent (the exact derivative of the discrete residual), so Newton converges quadratically. It is computed in two stages per Gauss point (_elem_tangent):

$$\mathbb C = \frac{\partial \sigma}{\partial \hat F}\Big|_{\hat F} \ \ (\texttt{jacfwd}\text{ of the model}),\qquad P(F, F_0) = \det F\,\Big(\sigma + \mathbb C : (\hat F(F,F_0) - \hat F) - qI\Big)\,F^{-T}$$ $$K_{aibk} = \sum_g w_g\,\frac{\partial N_a}{\partial X_J}\Big[\frac{\partial P_{iJ}}{\partial F_{kL}}\frac{\partial N_b}{\partial X_L} + \frac{\partial P_{iJ}}{\partial F_{0,kL}}\frac{\partial N^0_b}{\partial X_L}\Big]$$

The second term exists only for F-bar (\(F_0\) is the centroid deformation gradient).

Why two stages instead of jacfwd of the element residual
  • Cost. The material call is the expensive part. For the implicit HCMM it contains a Newton solve over \((z,\rho)\) for all constituents. Differentiating the whole element residual would push 24 (hex8) or 30 (tet10) tangent directions through 8 material calls. Two stages need only 9 directions (\(\hat F\) is 3×3) per Gauss point, and the remaining geometric part (\(\det\), \(F^{-1}\), F-bar scaling) is cheap.
  • Exactness is kept. \(P\) is built from the linearization of \(\sigma\) about \(\hat F\). Its derivative at that point equals the true derivative, so nothing is approximated.
  • F-bar for free. Writing \(P\) as a function of \((F, F_0)\) gives the extra centroid coupling of F-bar automatically. There is no separate hand-written F-bar tangent.
  • Hybrid block by hand. \(K_{uq}\) is just \(-\int J F^{-T}:\nabla N\), so it is written out directly (kuq) and reused as \(K_{qu}^T\).

The follower-pressure tangent of the faces is another jacfwd (_tangent). It is not symmetric (section 8).

8. Loads and boundary conditions

Follower pressure

$$f_a = -p\sum_g w_g\,N_a\,\Big(\frac{\partial x}{\partial\eta_1}\times\frac{\partial x}{\partial\eta_2}\Big)$$

The pressure acts on the deformed lumen surface (_face_force), as blood pressure does. At 10–15 kPa the wall stretches by 15–25 %, so a dead load would be noticeably wrong. The load stiffness this adds is not symmetric. That is one reason the global system is solved as non-symmetric. Faces are oriented outward when the mesh is built (mesh.outward), so the sign is consistent for any import.

Dirichlet, dead forces, slip

BC(fixed, values, f_dead, p, slip). Slip conditions \(u\cdot n = 0\) (inclined supports, symmetry planes not aligned with the axes) are handled by a null-space basis (Constraints):

$$x = x_p + Z\,y,\qquad \text{solve}\ \ Z^T K Z\,\delta y = -Z^T r$$

For every constrained node, the rows of fixed dofs (\(e_k\)) and slip normals (\(n\)) form a small matrix \(C\). \(Z\) spans its null space (SVD), and \(x_p = C^+ v\). Without slip conditions, \(Z\) is just a selection of the free dofs. In that case the code skips the matrix product and assembles directly into the pattern of the free dofs.

Why a null space and not a penalty or Lagrange multipliers

A penalty spoils the conditioning and is only approximate. Lagrange multipliers would add another saddle-point block on top of the hybrid one. The null-space method is exact, keeps the system as small as possible, and works equally for the adjoint (same \(Z\), transposed solve). It was needed for a tet10 cylinder rotated out of the coordinate axes (element_formulations, adjoint verified there).

9. Assembly

  • Element loop. jax.lax.map(..., batch_size=128) over elements, with vmap over Gauss points inside. The batch size limits memory: a G&R model under jacfwd creates large intermediates per Gauss point, so evaluating all elements at once can run out of memory on fine meshes, while one at a time would be slow.
  • Sparse pattern cached. The row and column indices of all element entries are built once (_rows, _cols). For each set of free dofs, _pattern computes the CSC structure and the map from element entries to non-zeros once. Each Newton iteration then only does one np.bincount over the tangent values. No COO→CSC conversion and no re-sorting happen per iteration.
  • Residual assembly is a scatter-add (.at[conn].add) inside the jitted residual.

10. Linear solver

The global matrix is non-symmetric (follower pressure, F-bar) and, with the hybrid element, indefinite with a zero diagonal block. That rules out Cholesky and CG. The code uses a sparse LU (LinearSolver):

MKL PARDISO (default)

  • mtype=11 (real non-symmetric), METIS nested dissection;
  • scaling + weighted matching (iparm[10], iparm[12]): moves large entries onto the diagonal, which is needed for the zero \(K_{qq}\) block;
  • pivot perturbation \(10^{-13}\);
  • symbolic analysis reused while the sparsity pattern is the same;
  • multithreaded only from 20k unknowns on (below that, thread overhead dominates); KMP_BLOCKTIME=0 so idle MKL threads do not spin and slow JAX.

SciPy SuperLU (fallback)

  • used when pypardiso is not installed;
  • ordering COLAMD for hybrid systems, MMD_AT_PLUS_A otherwise. The symmetric ordering assumes usable diagonal pivots, which the zero pressure block does not provide;
  • serial.

LU reuse: GMRES preconditioned with the previous factorization

Within a Newton loop, and between G&R steps, \(K\) changes only a little. The solver therefore first runs right-preconditioned GMRES with the last LU as preconditioner. It refactorizes immediately if GMRES does not reach the tolerance. If GMRES converged but needed more than 5 iterations, the old LU has become a poor preconditioner, so it is dropped and the next solve refactorizes. The result is accepted only if \(\|Ax-b\| \le 10\cdot\text{tol}\,\|b\|\) with tol \(=10^{-12}\). A converged Newton therefore stays quadratic, and the adjoint stays exact.

Why

The factorization is by far the most expensive linear-algebra step. A GMRES iteration costs one sparse mat-vec plus a pair of triangular solves. The same factorization also serves the transposed adjoint solve (trans="T"). Measured on vessel G&R end to end, compared with plain SuperLU: 12k dofs 1.2× faster (linear part 1.9×), 60k dofs 1.5× (linear 2.6×), a single factorization 23× at 79k. What remains is mostly JAX material/tangent evaluation.

11. Nonlinear solver: Newton and its fallbacks

_solve tries three strategies in order. Each is more robust and more expensive than the one before:

1. Newtonfull steps; converged when \(\max|r_u|/s_u < 10^{-10}\) and \(|r_q|/V_e < 10^{-10}\), or the step is below \(10^{-13}L\)
→
2. Load continuation\(bc(s) = (1-s)\,bc_{\text{last}} + s\,bc\); halve the increment on failure, double on success
→
3. Pseudo-transient continuation\((K + \eta\,|\mathrm{diag}\,K|)\,\delta x = -r\), \(\eta\times0.3\) per accepted step, \(\times10\) on rejection
  • Residual scale. \(s_u\) is the larger of the first residual and the dead forces. The criterion is therefore relative to the load. The pressure dofs are scaled by element volume, and in slip mode the scales are mapped through \(|Z|\) (restrict_scale).
  • Divergence detection. A non-finite residual, or one above \(10^8\), raises immediately and passes to the next stage.
Why pseudo-transient continuation

In a G&R step the load does not change; the material state does. When the wall snaps (buckling during growth), load continuation cannot help, because there is no load path to follow ("load unchanged, no continuation"). PTC adds artificial damping that is reduced towards zero. It stops only when the residual meets the same tolerance as Newton, i.e. at an exact equilibrium. The adjoint therefore needs no change. Verified on the shallow arch: from the limit state, Newton fails and relaxation reaches the arc-length end state to \(6\times10^{-12}\) in 20 iterations.

12. Buckling tools

  • arc_length(states, bc0, bc1). Crisfield's cylindrical arc length along \(bc(\lambda) = (1-\lambda)bc_0 + \lambda bc_1\), through limit points. The constraint \(|\Delta u|^2 = \Delta l^2\) uses only displacement unknowns. Hybrid pressures have different units and would distort the arc. \(\partial r/\partial\lambda\) comes from one jvp. The step size adapts as \(\sqrt{\text{target}/\text{iterations}}\). The G&R state is frozen, and the method is not differentiable.
  • stability(u, states, bc). Eigenvalues nearest 0 of \(Z^TKZ\,v = \mu\,B\,v\) by shift-invert. \(B\) is 1 on displacements and 0 on pressures, so the pressure multipliers produce no spurious eigenvalues. \(\mu < 0\) means unstable.
Why

Tortuosity and kinking of arteries are a buckling phenomenon under pressure and axial load, and a G&R state can lose stability. A perfect tube stays on the unstable symmetric branch under Newton. The tools give the critical load and the mode, which can then be added as an imperfection. Verified: Euler column within 1.5 % (discretization and shear), arch arc length equal to displacement control to \(9\times10^{-10}\).

13. The G&R time loop

$$\text{for each step: }\quad u_{n+1} = \texttt{equilibrium}(\text{state}_n, bc_{n+1}),\qquad \text{state}_{n+1} = \texttt{commit}(\text{state}_n, F(u_{n+1}))$$
  • Explicit HCMM (hcmm.core). sigma_solver evaluates the stress with the old \(\rho\), \(F_r\) and \(F_g\). commit then applies the Euler update of \(\rho\) and \(F_r\) on the converged \(F\). This is the same order as the UMAT (stress with the old \(F_r^{-1}\), then the update). Equilibrium sees a purely elastic material, which is cheap (≈ 0.1–0.2 µs stress, 1.5–3 µs tangent per Gauss point).
  • Implicit HCMM (hcmm.core_implicit). sigma_solver itself solves for \((z^j, \rho^j)\) at step \(n+1\) for the trial \(F\). The stress is therefore the backward-Euler G&R response, and commit only stores the result. The FE code does not change: its jacfwd of sigma_solver differentiates through the final Newton step of the inner solve, which gives the implicit-function-theorem tangent \(\mathrm d x/\mathrm dF = -J^{-1}\partial r/\partial F\). Cost per Gauss point ≈ 24–36 µs stress and 40–49 µs tangent.
  • commit pass-through. Leaves the model does not change (material parameters, fiber directions, \(\sigma_{\text{pre}}\)) are detected once from the jaxpr. They keep their input buffers instead of being copied every step. jax.checkpoint on the commit keeps the reverse pass from storing its intermediates.
Why staggered (equilibrium, then commit) and not monolithic

The G&R state is local to each Gauss point. Solving it inside the material call (implicit) or after equilibrium (explicit) keeps the global system the size of the mechanics only. A monolithic global system with \(\rho\) and \(F_r\) as unknowns at every Gauss point would multiply the system size without adding accuracy.

14. Adjoint: gradients through the simulation

equilibrium is a jax.custom_vjp. The forward pass is the full Newton solve (with all fallbacks). The backward pass does not differentiate through the Newton iterations. It uses the converged state:

$$(Z^TKZ)^T\,y = Z^T\bar u,\qquad \lambda = Z\,y,\qquad \overline{\text{state}} = -\lambda\cdot\frac{\partial r}{\partial\,\text{state}},\qquad \bar p = -\lambda\cdot\frac{\partial r}{\partial p}$$

The two products \(\lambda\cdot\partial r/\partial(\cdot)\) are one jax.vjp of the residual (residual_vjp).

Why
  • Exact and cheap. One transposed linear solve per step, reusing the LU. Differentiating through the Newton iterations would store every iterate and give the derivative of the iteration, not of the solution.
  • Independent of how the solution was found. Continuation and PTC do not affect the gradient, because only \(r(x^*)=0\) matters.
  • Memory over many steps. run(..., checkpoint=k) wraps blocks of \(k\) steps in a custom_vjp that recomputes the block in the reverse pass. Only every \(k\)-th state is stored, so memory scales as \(n/k\) instead of \(n\).

Results: adjoint vs central finite differences \(10^{-9}\) to \(10^{-11}\) (hex8, tet10 hybrid with inclined supports, hybrid box). On the artery (8,60,4), 100 steps: forward 36 s; value plus 9-parameter gradient 83 s, against about 640 s for finite differences. Identifying \((k_1, k_+)\) from \(\lambda_\theta(t)\) recovers the true values (loss \(3\times10^{-23}\)).

15. Geometry tools for real vessels

Wall basis from two Laplace problems (wall_basis)

$$\nabla^2\phi_r = 0,\ \phi_r|_{\text{inner}}=0,\ \phi_r|_{\text{outer}}=1;\qquad \nabla^2\phi_z = 0,\ \phi_z|_{\text{inlets}}=0,\ \phi_z|_{\text{outlets}}=1$$ $$e_r = \frac{\nabla\phi_r}{|\nabla\phi_r|},\quad e_z = \frac{\nabla\phi_z - (\nabla\phi_z\cdot e_r)e_r}{|\cdot|},\quad e_\theta = e_z\times e_r$$

Fiber directions (\(e_\theta\), \(e_z\), \(\pm\alpha\)) and the growth direction \(e_r\) need a local wall frame at every Gauss point. A segmented carotid has no analytic cylindrical coordinates. Two scalar Laplace solves on the same mesh and elements give a smooth frame on any geometry, including bends and bifurcations. On the bent stenotic tube, the G&R result with the Laplace frame differs from the analytic frame by \(10^{-5}\).

Prestress (in studies/artery.py, using fem.anderson)

The imaged geometry is already loaded. The elastin deposition stretch is updated, \(G \leftarrow F\,G\), until the mesh is in equilibrium at \(u = 0\) under the homeostatic pressure (Maes UMAT_DEP). Plain fixed-point iteration converges slowly, so it is Anderson-accelerated (type II, depth 5). On the bent stenotic tube this takes 23 iterations. The loop runs through equilibrium, so gradients pass through the prestress as well.

Mesh I/O and output

Structured generators (box, quarter cylinder, half tube, bent stenotic tube), Abaqus .inp (C3D8*, C3D10*, node sets, element sets, element-based surfaces) and gmsh .msh 2.2 / 4.1 read and write. Faces are reoriented outward on import. Output is VTK .vtu plus .pvd time series for ParaView (VTKSeries), with Gauss-point fields averaged to nodes and elements (fields, to_nodes).

17. Known limitations

  • F-bar has no hourglass stabilization. It is unusable for \(K/\mu \gtrsim 10^3\) in long G&R runs. Hybrid is the answer, so this was not pursued.
  • Q1/P0 is not LBB-stable in theory. No pressure modes have been seen on the tube meshes. On badly shaped or highly constrained hex meshes, check \(q\) for checkerboarding, or use tet10 (P2/P0).
  • Quasi-static only. There is no inertia, no fluid coupling and no wall-shear stimulus. The pressure is constant per phase.
  • The FCMM does not run in the FE code (memory for the per-Gauss-point cohort history).
  • Arc length and stability freeze the G&R state and are not differentiable.
  • Cost is dominated by the JAX material and tangent evaluation, especially with the implicit HCMM, not by the linear solver.
