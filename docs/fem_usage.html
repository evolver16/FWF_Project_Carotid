Using the FE code

How to set up and run a simulation with fem/: mesh, material, boundary conditions, solve, output, gradients, G&R models and Abaqus input files. All code blocks on this page have been run as shown.

Units: mm, MPa, days. Quasi-static, finite strain, total Lagrangian. Why the code is built this way: fem.html.

Meshfem.mesh: generator, .inp or .msh
→
Statesone material / mixture per Gauss point
→
Systemfem.System(mesh, model, pressure_faces, element)
→
BCfixed dofs, values, pressure, forces
→
Solveequilibrium or run
→
Outputstresses, reactions, VTK

1. Install

python -m venv ~/venvs/cmm && source ~/venvs/cmm/bin/activate
pip install -r cmm/requirements.txt
pip install -e .                 # fem, materials, verification importable; commands fem-abaqus, fem-vs-abaqus
pip install pypardiso            # optional: MKL PARDISO (much faster); without it SciPy SuperLU is used
  • Python ≥ 3.12, JAX, NumPy, SciPy. import fem switches JAX to float64, which the solver needs.
  • gfortran only for Abaqus user subroutines (UMAT, UHYPER).
  • G&R models live in cmm/ (hcmm, fcmm); run scripts that use them from cmm/.

2. Quick start: uniaxial tension of a cube

import numpy as np
import fem
import materials
from fem import mesh as meshlib

m = meshlib.box((4, 4, 4), (1.0, 1.0, 1.0))                 # 64 hex8, unit cube
states = fem.broadcast_state(materials.NeoHookean(0.5, 50.0), m.n_elem, len(m.element.gauss))
sysm = fem.System(m, element="fbar")

x0, y0, z0, x1 = m.nodes[(0, -1)], m.nodes[(1, -1)], m.nodes[(2, -1)], m.nodes[(0, 1)]
fixed = np.concatenate([3 * x0 + 0, 3 * y0 + 1, 3 * z0 + 2, 3 * x1 + 0])     # dof = 3 node + component
end = np.concatenate([np.zeros(len(x0) + len(y0) + len(z0)), np.full(len(x1), 0.5)])
bcs = [fem.BC(fixed, s * end) for s in np.linspace(0.1, 1.0, 10)]          # 10 load steps

u, states, _ = sysm.run(states, bcs)
sig = sysm.total_stress(u, states)                          # Cauchy, (n_el, n_gp, 3, 3)
print(sig[..., 0, 0].mean())                                # 1.54967 (Abaqus: 1.54967)

3. Meshes

A Mesh holds X (n_nodes, 3), conn (n_el, 8 | 10 | 4), and dictionaries nodes (node indices), faces (outward-oriented quad4 / tri6 / tri3 node lists) and elsets. Indices are 0-based.

The structured generators take etype="hex8" | "tet10" | "tet4" (tets: 6 per cell, curved tet10 edges); carotid_bifurcation is hex8 only. Imported faces are reoriented outward automatically. Elements with \(\det(\partial X/\partial\xi) \le 0\) are rejected when the System is built.

m = meshlib.read_inp("vessel.inp")
inner_faces, inlet_nodes = m.faces["INNER"], m.nodes["INLET"]     # names as in the file

4. Materials and the state per Gauss point

The solver asks the model for the Cauchy stress at each Gauss point; the state holds what the model needs there. Without a model (System(mesh)) the state is simply a material object with sigma(F).

materialenergyuse with
materials.NeoHookean(C10, K)\(C_{10}(\bar I_1 - 3) + \tfrac K2 (J-1)^2\)standard, fbar
materials.NeoHookeanInc(C10)\(C_{10}(I_1 - 3)\), deviatoric stress onlyhybrid, hybrid_p1 (incompressible)
materials.Fung(k1, k2, M)\(\tfrac{k_1}{2k_2}[e^{k_2(I_4-1)^2}-1]\), tension only, fiber direction Many
n_gp = len(m.element.gauss)                       # 8 hex8, 4 tet10, 1 tet4
states = fem.broadcast_state(materials.NeoHookean(0.5, 50.0), m.n_elem, n_gp)   # leaves (n_el, n_gp, ...)

Parameters that vary in space: build the state with arrays of shape (n_el, n_gp) instead of broadcasting (Gauss point coordinates: fem.gauss_points(m.X, m.conn)). The state is a JAX pytree, so it can be differentiated (section 9).

5. Choosing the element formulation

element=mesheswhen
"standard"hex8, tet10, tet4compressible material (\(K/\mu \lesssim 20\)); tests
"fbar"hex8, tet10, tet4nearly incompressible, short runs; not for long G&R with \(K/\mu \gtrsim 10^3\)
"hybrid"hex8 (Q1/P0), tet10 (P2/P0)default for arterial G&R on hex8, with NeoHookeanInc; enforces \(J = J_\text{target}\)
"hybrid_p1"tet10 only (P2/P1)default on tet10; smooth, convergent pressure and wall stress
Note

hybrid makes the material exactly incompressible (up to growth via the model's J_target). It is not Abaqus' compressible hybrid; for a compressible material use fbar.

6. Boundary conditions

fem.BC(fixed, values, f_dead=None, p=0.0, slip=None, wss=None)
fieldmeaning
fixed, valuesprescribed global dofs (\(3\,\text{node} + c\), \(c\) = 0, 1, 2) and their displacements
f_deaddead nodal forces, length n_dof
pfollower pressure on System(..., pressure_faces=...): a number, one per face, or one per face Gauss point
slip(nodes, normals): \(u\cdot n = 0\), for inclined supports and symmetry planes not aligned with the axes
wsswall shear stress on the pressure faces (G&R stimulus, passed to the model's wss; not a traction)

Example, pressurized quarter cylinder (symmetry planes, plane strain):

m = meshlib.quarter_cylinder(n=(4, 24, 1))
states = fem.broadcast_state(materials.NeoHookeanInc(0.305), m.n_elem, len(m.element.gauss))
sysm = fem.System(m, pressure_faces=m.faces[(0, -1)], element="hybrid")
fixed = np.unique(np.concatenate([3 * m.nodes[(1, -1)] + 1, 3 * m.nodes[(1, 1)] + 0,
                                  3 * m.nodes[(2, -1)] + 2, 3 * m.nodes[(2, 1)] + 2]))
bc = fem.BC(fixed, np.zeros(len(fixed)), p=0.016)            # 16 kPa
u = sysm.equilibrium(states, bc, np.zeros(sysm.n_dof))

Support forces in an equilibrium: sysm.reaction(u, states, bc) (length n_dof, nonzero at the fixed dofs). Adding them to f_dead and releasing the support holds the same state with force control (e.g. isotonic vessel ends).

7. Solving

callreturnsuse
sysm.equilibrium(states, bc, u0, tol=1e-10)uone load state; differentiable
sysm.run(states, bcs, u0=None, on_step=None, checkpoint=None)(u, states, history)sequence of steps: equilibrium, then commit of the state; history = on_step(u, states) per step
sysm.solve(u0, states, bc)(u, iterations)plain Newton, not differentiable
sysm.commit(u, states)statesclose a step by hand (after equilibrium)

Newton converges when the scaled residual is below tol. If it fails, the solver automatically falls back to load continuation (halving the step from the last converged BC), then pseudo-transient relaxation (for snapping without a load change). Diagnostics: sysm.last_iterations, sysm.cutbacks, sysm.relaxations. Hybrid pressures: sysm.last_p.

Results: sysm.total_stress(u, states) (Cauchy incl. hybrid pressure, per Gauss point), sysm.gauss_F(u) (deformation gradient), sysm.to_nodes(values) (Gauss → nodes).

8. Output and ParaView

series = meshlib.VTKSeries("out/box.pvd")                   # .pvd + one .vtu per call
on_step = lambda u, st: series.write(len(series.entries), m.X, m.conn, *sysm.fields(u, st))
u, states, _ = sysm.run(states, bcs, on_step=on_step)

sysm.fields(u, states, gauss=None) returns (point_data, cell_data) with u, J, σ, von Mises (and \(\rho/\rho_0\), \(J_g\) for mixtures); extra Gauss-point fields go in gauss={"name": array (n_el, n_gp, ...)}. In ParaView open the .pvd and use Warp By Vector on u (docs/paraview/warp_u.py).

9. Gradients

equilibrium and run are reverse-differentiable with respect to the states (all material and model parameters) and the pressure bc.p, through an adjoint solve per step. Use jax.grad as usual:

import jax
inner = m.nodes[(0, -1)]

def f(C10, p):
    st = fem.broadcast_state(materials.NeoHookeanInc(C10), m.n_elem, len(m.element.gauss))
    u = sysm.equilibrium(st, fem.BC(fixed, np.zeros(len(fixed)), p=p), np.zeros(sysm.n_dof))
    return u.reshape(-1, 3)[inner, 0].mean()

dC10, dp = jax.grad(f, argnums=(0, 1))(0.305, 0.016)
  • Prescribed displacement values and f_dead are not differentiated; put a parameter into the state or the pressure instead.
  • Long runs: run(..., checkpoint=k) stores only every \(k\)-th state and recomputes in the reverse pass (memory \(\sim n/k\)). on_step must then return JAX values.
  • Cost: about 2–3 forward runs for the full gradient, independent of the number of parameters.

10. G&R models and your own model

A model is any object or module with

sigma, aux = model.sigma_solver(state, F)   # Cauchy stress at a trial F; must not change state
state      = model.commit(state, F, aux)    # once per step, on the converged F
J_target(state)                             # optional: target volume ratio for the hybrid element (growth)
wss(state, tau_w) -> state                  # optional: receives BC.wss

Both functions are written for one Gauss point; the FE code vectorizes them. The tangent comes from AD.

G&R with the HCMM

import hcmm                                      # from cmm/
sysm = fem.System(m, hcmm, pressure_faces=m.faces[(0, -1)], element="hybrid")
# states: one mixture per Gauss point, see studies/model_e.py (assemble, artery_simulate):
# prestress the imaged geometry at p_hom, then run G&R steps of ds days at p_gr
u, states, history = sysm.run(states, [bc] * n_steps, u0=u, on_step=measure)

Working templates: cmm/studies/model_e.py (artery_simulate: prestress with Anderson acceleration, G&R loop, gradients), cmm/studies/artery.py (pressure and flow steps), cmm/studies/carotid.py (bifurcation).

Own model, minimal example

from fem.pytree import pytree
from fem.tensor3 import det3

@pytree(("C10", "K"))                            # leaves of the state
class Soft:
    def __init__(self, C10, K):
        self.C10, self.K = C10, K

class Softening:                                 # neo-Hooke whose C10 drops 10 % per step
    @staticmethod
    def sigma_solver(state, F):
        return materials.NeoHookean(state.C10, state.K).sigma(F) / det3(F), None

    @staticmethod
    def commit(state, F, aux):
        return state.replace(C10=0.9 * state.C10)

sysm = fem.System(m, Softening)
states = fem.broadcast_state(Soft(0.5, 50.0), m.n_elem)
u, states, hist = sysm.run(states, [bc] * 3)

11. Buckling

mu, modes = sysm.stability(u, states, bc, k=4)        # eigenvalues nearest 0; mu < 0: unstable
path = sysm.arc_length(states, bc0, bc1, n_steps=20)  # [(lam, u)] for bc(lam) = (1-lam) bc0 + lam bc1

Both freeze the G&R state and are not differentiable. bc0 and bc1 must fix the same dofs. A perfect structure stays on the symmetric branch under Newton: add a scaled mode from stability as imperfection.

13. Abaqus input files and user subroutines

13.1 Run an .inp with fem.System

fem-abaqus job.inp [umat.for more.for] [--out dir] [--element fbar]

Supported: one part, one material (*User Material, *Hyperelastic, user (UHYPER) or *Hyperelastic, neo hooke), C3D8*, C3D10*, C3D4*; *Static steps with *Boundary (incl. XSYMM … ENCASTRE), *Dsload P, *Cload, *Field, *Initial Conditions (FIELD, SOLUTION via SDVINI), *Amplitude (tabular, smooth step), *Parameter. Unsupported keywords (contact, ties, dynamics, …) raise an error instead of being ignored.

Abaqus elementfem formulation
C3D8, C3D8Rfbar
C3D10, C3D4standard
C3D8H, C3D10H, C3D4H, incompressible materialhybrid
C3D8H, C3D10H with a compressible materialfbar

Increments are fixed (initial increment with direct, else the maximum increment); non-converging increments are cut back internally. Output in <out>: job.pvd, job_rf.csv (reaction sums per boundary set), job_fem.npz.

13.2 Compare with Abaqus

Abaqus runs on the host, JAX in the container. The script splits accordingly:

# host (needs only Abaqus and Python 3 standard library)
python3 fem/abaqus_interface/vs_abaqus.py job.inp umat.for --abaqus-only        # → vs_job/job_odb.npz, timing

# container
fem-vs-abaqus job.inp umat.for --skip-abaqus                                     # runs fem, compares, vs_job/job_vs_abaqus.txt

The comparison prints, per common time, \(\max|\Delta U|/\max|U|\), \(\max|\Delta S|/\max|S|\) (element means), SDV and reaction sums. Options: --cpus, --repeat, --out, --export-only (only re-export an existing .odb). Already-run comparison: fem-abaqus compare job_fem.npz job_odb.npz job.inp.

13.3 UMAT / UHYPER directly in Python

from fem.abaqus_interface.umat import Umat, Uhyper

umat = Umat(["verification/umat/neohooke.for"], nstatv=4, sdvini=True)   # compiled with gfortran, cached
states = umat.state(m, [0.305, 6.1], dtime=1.0)                           # PROPS; per point: (n_el, n_gp, n_props)
sysm = fem.System(m, umat, element="fbar")
u = sysm.equilibrium(states, bc, np.zeros(sysm.n_dof))
states = sysm.commit(u, states)                                           # STATEV, TIME, KINC advanced
# states.statev: (n_el, n_gp, nstatv)

uhyper = Uhyper(["verification/umat/mooney_rivlin.for"])                 # *Hyperelastic, user
  • The tangent is built from DDSDDE (Jaumann rate, as in Abaqus); for UHYPER from UI1 / UI2.
  • Fixed or free form is detected (!dec$ freeform); other files in the folder can be INCLUDEd.
  • Stress is evaluated from the start-of-increment STATEV, STATEV are written at commit, as Abaqus does.

15. Troubleshooting

symptomcause / fix
elements with det(dX/dxi) <= 0inverted or wrongly ordered elements in the mesh; check the node order of the imported element type
Newton slow, many cutbacksload steps too large, or standard with a nearly incompressible material (locking): use fbar / hybrid
Newton fails in a long G&R run with F-barhourglass-type modes for \(K/\mu \gtrsim 10^3\): switch to hybrid + NeoHookeanInc
linear solve: relative residual …singular system: rigid-body modes not fixed, or a stress-free hybrid mesh without enough supports
slow linear solvespip install pypardiso; without it SuperLU runs serially
out of memory on fine meshesSystem(..., batch=32) (elements per evaluation batch, default 128)
residual stalls around 1e-7float32: import fem before creating JAX arrays (it enables float64)
